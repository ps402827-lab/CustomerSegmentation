# Customer Segmentation, Sales Forecasting & Recommendation System

## 📌 Project Overview

This project is a Data Analytics project that analyzes customer behavior, sales performance, and product data to generate useful business insights.

The project uses Python, SQL, Power BI, and CSV datasets to perform data analysis, customer segmentation, sales forecasting, and product recommendations.

## 🎯 Objectives

- Analyze customer purchasing behavior
- Segment customers based on their characteristics and purchasing patterns
- Analyze sales and revenue performance
- Identify top-performing products and categories
- Forecast future sales
- Provide product recommendations
- Create an interactive Power BI dashboard
- Generate business insights for better decision-making

## 🛠️ Tools & Technologies

- **Python** – Data cleaning, EDA, customer segmentation and analysis
- **Pandas** – Data manipulation
- **NumPy** – Numerical analysis
- **Matplotlib** – Data visualization
- **SQL / MySQL** – Data querying and analysis
- **Power BI** – Interactive dashboard and visualization
- **Jupyter Notebook / Google Colab** – Python analysis
- **Git & GitHub** – Project version control

## 🔍 Project Workflow

### 1. Data Collection
Collected customer, order, and product data using CSV files.

### 2. Data Cleaning
- Checked missing values
- Removed duplicate records
- Corrected data types
- Prepared datasets for analysis

### 3. Exploratory Data Analysis
Performed analysis to understand:
- Customer behavior
- Sales trends
- Product performance
- Revenue patterns

### 4. Customer Segmentation
Customers were analyzed and grouped based on their purchasing behavior to identify different customer segments.

### 5. Sales Forecasting
Historical sales data was analyzed to identify trends and estimate future sales performance.

### 6. Product Recommendation
Customer purchase behavior was analyzed to identify suitable product recommendations.

### 7. Power BI Dashboard
An interactive Power BI dashboard was created to visualize:

- Total Sales
- Total Revenue
- Total Customers
- Customer Segments
- Product Performance
- Sales Trends
- Regional Performance
- Customer Retention

## 📊 Key Business Insights

The analysis helps businesses understand:

- Which products generate the highest sales
- Which customer segments are most valuable
- How sales change over time
- Which regions perform best
- Customer purchasing behavior
- Future sales trends
- Products that can be recommended to customers

## 📈 Dashboard

The Power BI dashboard provides interactive charts, KPIs, filters, and customer segmentation analysis for easy business decision-making.
